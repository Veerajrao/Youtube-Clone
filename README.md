# 📺 YouTube Clone

A front-end clone of YouTube built using **HTML5 and CSS3** to practice core web development concepts and recreate the layout of a familiar video-sharing platform.

The project focuses on webpage structure, styling, layout management, and responsive design.

## 🚀 Features

- YouTube-inspired user interface.
- Structured layouts using CSS Grid.
- Organized page elements and content sections.
- CSS positioning and stacking using `z-index`.
- Responsive layout design.

## 🛠️ Technologies Used

- **HTML5** – For structuring the webpage.
- **CSS3** – For styling, layouts, positioning, and responsiveness.

## 📚 Concepts Learned

While building this project, I practised:

- Writing structured HTML.
- CSS Grid for creating organized layouts.
- CSS positioning and the `z-index` property.
- Managing element stacking and layering.
- Responsive web design.
- Improving webpage layout and visual consistency.
- Understanding how HTML and CSS work together to build user interfaces.

## 🎯 Purpose of the Project

The main objective was to strengthen my front-end development fundamentals through practical implementation and gain a better understanding of how real-world website interfaces are structured and styled.
